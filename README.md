# Nater's Tournament

A Geode mod for live 1v1 Geometry Dash tournaments, made for Nater's streams.

- **Main menu**: the tournament badge sits in its own spot left of the main buttons (not in the bottom row, where other mods put theirs).
- **Tournament list**: browse public tournaments, or join a private one with its 5-letter code.
- **Create**: name, public or private, player count, time limit, and which difficulties the levels come from (Easy to Extreme Demon; tap each to switch it on or off).
- **Lobby**: players drop in with a poof, land and wave hello, then walk around with A/D or the arrow keys (W, Up or Space to jump, or tap the ground). Everyone sees everyone move. Hosts can add practice bots.
- **Levels**: the host rolls a random featured level from the chosen difficulties for each round, Versus-style. A roulette of difficulty faces slows down and slams onto the level, on every screen. The host can reroll.
- **Bracket map**: every fighter stands on their own spot with their own sword. While a match is live the two trade blows (wind-up, lunge, clash or hit), and whoever is further into the level presses harder. When it ends, the winner cuts straight through the loser, who bursts a beat later, raises the sword and walks the lit path to the next round. The champion takes the trophy.
- **Matches**: a VS screen where both draw swords and point them at each other, a synced countdown, then both players race on the same level. The level's HUD shows your opponent's live run, their best %, the clock and their emotes.
- **Emotes**: Nater's own Timer Battles emotes.

| GD 2.2081 with Geode v5 (not updated yet) | [latest-2.2081](https://github.com/Natertater534/naters-tournament/releases/tag/latest-2.2081) |

Put the `.geode` file in your Geode mods folder and restart the game. To find that folder, open Geode from the main menu and click the folder button. Players on different game versions can't be in the same tournament.

## Building

GitHub Actions builds every push to `main` for both game versions, for Windows and Android:

- `.github/workflows/build-2.2091.yml` uses Geode v6.0.0.
- `.github/workflows/build-2.2081.yml` uses Geode v5.11.2, with bindings pinned to the last 2.2081-only commit.

The server is Supabase Postgres. `server/schema.sql` holds every table and RPC function. The mod calls the functions directly with the project's publishable key, and the tables can't be reached any other way.

No Versus art or sounds are used, and no GD Versus art either: the badge, swords and effects are this mod's own.
